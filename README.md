--simulation_f1_pole.py--

Python project which applies supervised machine learning, specifically linear regression, to predict Formula 1 pole lap times (Q3). 
It leverages historical data from FP1, FP2, FP3, and Qualifying sessions across 2018-2025, filtering for dry conditions only 

--f1_plot_fastf1.py--

Developed Python scripts using the FastF1 library to collect and analyse Formula 1 telemetry data
Generated race pace and strategy visualisations
